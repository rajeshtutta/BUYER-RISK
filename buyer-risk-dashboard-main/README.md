
# Buyer Risk Dashboard

## Project Structure

- frontend -> React frontend
- backend -> FastAPI backend
- database -> PostgreSQL schema

## Frontend Setup

cd frontend
npm install
npm start

## Backend Setup

cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload

## Database Setup

Run schema.sql in PostgreSQL.

## Application URLs

Frontend:
http://localhost:3000

Backend:
http://localhost:8000
